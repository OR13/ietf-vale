# ExamplePhone

For example, call +1-202-555-0200 for the test service.
For documentation, do not use +1-202-555-1234.
For UK documentation, use +44-20-496-1234 or not +44-20-496-2345.

These must stay clean: the support number is +1-202-555-0199, and a version
number such as 1-202-555-1234 is not a telephone number. A real UK number such
as +44-20-496-0123 is also reserved for examples.
