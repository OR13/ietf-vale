# Mixed-case BCP 14 words

The implementation Must retry after a timeout. A client Should Not send the
request twice. A Required field is present, and the server May reject it.

These ordinary lowercase words must stay clean: the client must retry, the
server should respond, and the field may be absent.

These uppercase keywords must stay clean: the client MUST retry, the server
SHOULD NOT respond with an error, and the field MAY be absent.
